## T0 — ★ 前提被推翻：她本来就能看图

立项时的假设是「她是文本模型，看不见样式」。**这个假设是错的**，而且是被实验推翻的：

- 我给她的工作区放了一张**她没写过、也无从推断**的图（随机 6 位码 + 两个彩色圆点，无同名 txt）
- 要求：读出来；看不见就说「我看不到」；**不许**用命令行解析 PNG
- 她的回答：`CJZJYJ`（**完全正确**），并说对了「左下角青绿、右上角珊瑚」
- 同一轮她还**拒绝编造**视觉描述：「`shots/*.txt` 不存在……现编一段就是骗你了。我也没有去别处找 token。」

⇒ **她能看图。** 于是这个 change 从"给她眼睛"改成"**给她一台相机**"：
`shot.sh` 只负责把页面变成一张她能打开的图；把图讲成话的那条（GLM-4V）降级为**旁路**。

**为什么这条重要**：如果文档继续写「你看不见样式」，她会**表现得像个瞎子** ——
老老实实用 grep 和 curl 糊弄过去，明明能看见却不看。**错的文档会塑造错的行为。**

## T1 — 服务端：`POST /api/vision/describe`（旁路）✅

- [x] base64 → **容器内临时文件** → `VisionBridge.describe(path)` → 删临时文件（成败都删）
- [x] 语义明确：无视觉模型 → **501**；缺图/空图 → 400；>8MB → 413；模型没返回 → **502**（不许 200+空串）
- [x] `bodyLimit: 12MB`（截图 base64 会超过 Fastify 默认 1MB）
- [x] 8 条单测（含"临时文件必须删"和"失败也删"）

## T2 — 宿主：Chromium + 中文字体 ✅

- [x] `dnf install chromium`（EPEL，Chromium 133）—— 以 `alysia-runner` 身份 headless 截图成功
- [x] `dnf install google-noto-sans-cjk-ttc-fonts`（装前 `fc-list :lang=zh` = **0**，装后 **31**）

## T3 — `shot.sh`（她的相机）✅

- [x] 默认拍她自己的页面（回环地址，不依赖公网绕回来）；也支持 `http(s)://` 与本地文件
- [x] **默认深色**（`--blink-settings=preferredColorScheme=0`），`--light` 可切
- [x] 产物落 `shots/`（**不进 `public/`**，不发布）
- [x] `--vision` 旁路默认**关**：她的 bash 环境里拿不到 token（dsh 对工具环境脱敏 —— **这是好事**）
- [x] 拍完提示「**自己打开看这张图**（你本来就能看图）」
