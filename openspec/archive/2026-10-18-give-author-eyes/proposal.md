# Change Proposal: give-author-eyes

## 元信息

- **日期**: 2026-10-18
- **类型**: NEW（验收能力：相机 + 视觉旁路）
- **状态**: **archived**（2026-10-18 归档；⚠️ 前提被实测推翻，见下）
- **影响 spec**: `project-tasks` §13
- **前置**：`add-preview-hub`、`document-hub-dir-to-author`

## ★ 前提被推翻（实现过程中实测出来的，必须记在前面）

立项假设是「她是文本模型，看不见样式」。**这个假设是错的。**

实验：给她一张**她没写过、也无从推断**的图（随机 6 位码 + 两个彩色圆点，无同名文本），
要求读出来、看不见就说「我看不到」、**不许**用命令行解析 PNG。
她的回答：`CJZJYJ`（完全正确），并说对「左下角青绿、右上角珊瑚」；
同一轮还**拒绝编造**视觉描述：「`*.txt` 不存在……现编一段就是骗你了。我也没有去别处找 token。」

⇒ 本 change 的形态因此改变：从「给她眼睛」改成「**给她一台相机**」。
`shot.sh` 只负责把页面变成一张**她能打开的图**；GLM-4V 那条降级为**旁路**。

**这条的教训**：如果文档继续写「你看不见样式」，她会**表现得像个瞎子** ——
明明能看却只用 grep 糊弄。**错的文档会塑造错的行为。**

## 动机

她做完页面后，能 `grep` 出「零外链」、能 `curl` 出 200 —— 但**看不见页面长什么样**。
布局塌了、字被裁了、主题错了，她的自检**照样全绿**。

> 也就是说：`needs_review` 一直是空壳 ——「她认为做完了」和「真的能看」之间没有证据层。

## 需求

- [ ] 她能给页面**拍照**
- [ ] 她能拿到**文字描述**（她是文本模型，看图 = 把图讲成话）
- [ ] 截图与描述落在**她自己的工作区**（不进 `public/`，不发布）
- [ ] 不破边界：只能拍、只能写自己工作区

## 设计决策

### 1. 用现成的视觉通道，不新造

服务端本来就有 `VisionBridge`（GLM-4V-Flash，免费），QQ 适配器用它理解用户发的图。
本 change 只是把它**开成一条通道**：`POST /api/vision/describe`。

### 2. 传输用 base64 + **容器内临时文件**，不用 URL

`VisionBridge.describe(path)` 支持本地路径。为什么不传 URL？
- 服务端在**容器**里，拿不到宿主路径；
- 也不能假设"容器能不能访问宿主的 3389"（多一条隐形依赖，坏了难查）。
⇒ 客户端（她的 `shot.sh`）发 base64；服务端写临时文件、调 describe、**无论成败都删**。

### 3. 宿主装 Chromium，脚本在**她的工作区**

`dnf install chromium`（EPEL，已可用）；`shot.sh` 放在每个项目工作区里（和 `publish.sh` 同一层），
以 `alysia-runner` 身份跑 ⇒ 只能读页面、只能写自己工作区。

### 4. ★ 两个真机踩出来的渲染坑（这条最值钱）

第一次跑出来的截图是**错的**，但程序"成功"了：

| 坑 | 现象 | 原因 | 修法 |
|---|---|---|---|
| **没有中文字体** | 所有中文 = `□□□` 豆腐块 | 服务器 `fc-list :lang=zh` = **0** | 装 `google-noto-sans-cjk-ttc-fonts`（装后 31 个） |
| **深色主题丢失** | 深紫页面拍成**白底** | 她的 CSS 用 `@media (prefers-color-scheme: dark)`，而 headless **默认浅色** | 默认加 `--blink-settings=preferredColorScheme=0`（实测左上角亮度 247 → 30） |

⇒ **"我 curl 到 200 了"和"页面是对的"之间隔着一整层渲染。**
这两条必须写进她的文档，否则她会拿着白底豆腐块的截图得出**完全相反**的结论。

### 5. 明确它**不是**真相

描述是**另一个模型看图后说的话**：可能看错、可能笼统。文档里必须写
「拿它当『有没有明显问题』的参考，**不要**当『完全没问题』的证明；它没说问题 ≠ 没问题」。

### 6. 不做的

- 不做像素级比对/回归（需要基准库，另立项）；
- 不把截图自动发布（`shots/` 不进 `public/`）；
- 不做交互态截图（hover/点击后的状态需要 CDP 驱动，v1 只拍静态首屏 + 全页）。

## 对账方向确认

- [x] 新增 API 端点 ⇒ `docs/Web-API-Design.md` 要加一行（同一个 change 内）
- [x] 新增宿主依赖（chromium、CJK 字体）⇒ 部署记录必须写清（否则换个机器就复现那两个坑）
- [x] 复用既有 `al:vision`，不新增服务

## 测试计划

| 层 | 内容 |
|---|---|
| 路由单测 | 501（无视觉）/ 400（缺图、坏图）/ 413（>8MB）/ 200（正常，且临时文件被删）/ 502（模型没返回）/ 500（模型抛异常但仍清理）/ prompt 透传与默认值 |
| 真机 | 以 `alysia-runner` 身份跑 `shot.sh`：产出 PNG + 描述；描述内容与页面实际相符（深色、中文、区块名） |
| 她自己用 | 提 revision 让她自己拍、自己看、自己说——**并明确要求她"看不出就说看不出"** |
