# Change Proposal: gate-project-tasks-to-offpeak

## 元信息

- **日期**: 2026-10-18
- **类型**: NEW（成本闸门 / 调度约束）
- **状态**: archived（2026-10-18 归档；T1–T6 完成，真机双向验证）
- **影响 spec**: `project-tasks` §14
- **前置**：`claim-across-projects`（认领模型）

## 动机（用户原话）

> 「我们的事件也要加上做网站这个东西，不过这个命令**限制在 DeepSeek API 的空闲时段**，
> 北京时间周一至周五（不含中国法定节假日）9:00–12:00、14:00–18:00 为高峰时段；
> 其余时段，包括周末及中国法定节假日全天均为空闲时段。」

⇒ 「做网站」这类**要烧 API 的活**不该在高峰期跑。

## 需求

- [ ] 高峰时段**不执行**（钱按执行时间算）
- [ ] 但**不拒收**任务（拒收等于让用户和模型都去记时段）
- [ ] 周末 / 法定节假日**全天**可跑
- [ ] 判定必须**不看宿主时区**（容器常是 UTC，错 8 小时会让高峰跑到凌晨）
- [ ] 加闸门之后，"我的任务为什么不动"必须有答案

## 设计决策

### 1. 闸门做在**认领侧**，不是提交侧

任务随时可交，留在 `queued`；runner 每轮问 `/next`，服务端在高峰时回
`{ok:true, task:null, paused:{...}}`。

- **钱**：调度本身不花钱，执行才花 ⇒ 排队零成本；
- **体验**：她/用户不必记时段；到点自己跑；
- **可解释**：`paused.message` 直接告诉她"要等到 12:00 之后，**不用再交一次**"
  （否则她会重复提交）。

### 2. 时区一律自己算（UTC+8），**不用** `getHours()`

中国不实行夏令时，恒定 +480 分钟。用宿主本地时间会在 UTC 容器里整体错 8 小时，
把"高峰"搬到凌晨 —— 那是最坏的一种"看起来生效了"。

### 3. 节假日表**不内置**

法定节假日每年公布、还涉及调休；**猜一份错的表比没有更糟**
（会把该省钱的假日当工作日，或反之）。
由 `projectTasks.holidays` 提供；**未列出的日期按工作日处理** ⇒ 窗口照常生效
⇒ 只会更省，不会多花。

### 4. 排障入口：`GET /api/project-tasks/window`

加闸门后第一个问题一定是"为什么不动"。这个只读端点返回
`{window:{offPeak,reason,nowBeijing,until,message}, config:{peakWindows,holidays,nowOverride}}`。

### 5. `nowOverride`（**排障用**，会被 WARN）

高峰分支只在工作日 9-12/14-18 触发 —— 想在生产上验证"闸门真拦得住"，只能等到周一上午。
提供 `projectTasks.nowOverride`（ISO）来固定判定时刻，**配了就打 WARN**，用完即删。

### 6. 不做的

- 不做"按价格自动切换模型"（那是另一件事）；
- 不做跨时区日历（她用北京时区，没有第二个时区）；
- 不做节假日自动同步（外部数据源、权威性、失效都要处理，先手工配）。

## 对账方向确认

- [x] 新增 core 纯函数 `computeTaskWindow()` + barrel 导出（服务端与工具共用同一份规则）
- [x] 新增只读端点 `/api/project-tasks/window` ⇒ `docs/Web-API-Design.md` 要加一行
- [x] 新增配置段 `projectTasks` ⇒ `loadConfig()` **必须**同时加映射（这个坑踩过）

## 测试计划

| 层 | 内容 |
|---|---|
| 窗口纯函数 | 边界（9:00/12:00/14:00/18:00 左闭右开）、周末、节假日、**UTC 与北京换算**、跨日、窗口可覆盖 |
| 路由 | 高峰 → `task:null + paused` 且**不许认领**；空闲 → 照常；周末/节假日 → 照常；`/window` 说清依据；`nowOverride` 与注入时钟等价 |
| 工具 | 高峰提交**仍收下**、回执带"高峰"与"不用再交一次"；空闲/周末不提高峰 |
| 真机 | 固定时钟到周一 10:15 → 任务停在 `queued`、runner 只报**一次**暂停；删掉 override → 自动开跑 |
