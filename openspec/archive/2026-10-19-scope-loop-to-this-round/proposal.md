## 动机（为什么做）

2026-10-18 夜，用户 QQ 实测「让她做个网站」，一夜之内撞了三个洞，**每一次都让一整轮白跑**：

| # | 现象 | 证据（线上） |
|---|---|---|
| 1 | **她的真页面被没收** | `island.html`（86 KB）+ `vendor/three.min.js` + 63 张截图，在 sketch 轮末尾被整批移进 `.phases/violations/r2/`；上一轮更狠：**988 个文件** |
| 2 | **闸门不看她这一轮做了什么** | 同一工作区做第二个任务时，上一轮留下的 `drafts/a,b,c.html` 与 `shots/draft-*.png` 还在 ⇒ sketch 闸门「6 个草图都有截图」直接放行；`NOTES.md` 的「自评」「选的」同理 |
| 3 | **build 阶段 1800s 必超时** | 海岛那轮 build 卡在 npm 下 three.js + 反复截图，**1801s 被 SIGKILL** ⇒ `unknown`（有意不自动重投）⇒ 任务卡死；用户只能重开，重开又从 `intent` 走一遍六阶段 |

**共同根因**：状态机假设「每个任务都在干净工作区从头做」，而现实是**同一个工作区反复做同一类东西** ——
判据读全工作区、白名单按路径不按权限，两边都不带"这一轮"的坐标。

## 需求（做什么）

- [ ] **写权限按能力分层**：只有 `public/**`（= 上线）是权限边界，只有 `publish` 阶段可写；
      `NOTES*.md` / `drafts/` / `shots/` / `vendor/` / 根目录页面与资源 = 她的工作产物，**任何阶段都许写**
- [ ] **判据只看本轮**：`drafts` / `shots` / 根目录页面 按 `mtime ≥ 本轮开始` 过滤；
      `NOTES.md` 的「意图 / 自评 / 选的 / 哪里像我」要求**本轮动过笔记**（`notesMtime ≥ sinceMs`）
- [ ] **超时按阶段给**：`build` 5400s、`sketch`/`revise` 2400~3600s、`intent`/`review`/`statement` 900s；
      `--timeout` 显式传入时仍然是**所有阶段的统一上限**（排障/演示用）
- [ ] **`.tmp/` 不再进快照**：它是工具缓存（npm-cache、chrome 日志），不进快照 ⇒ 不会被判越界、
      也不会每轮生成上千条"阶段外写入"噪音
- [ ] 越界（只剩 `public/**` 和真正意外的路径）仍然**移出但保存**，并在回执里如实说

## 设计决策（怎么做，含备选与取舍）

1. **为什么"不设阶段限制"是对的**：白名单原本要挡的是「她越过 `allowPublish` 偷偷上线」——
   那是**权限**问题，对象是 `public/`。而她提前写整页是**过程纪律**问题，
   正确的杠杆是**判据**（这一轮该做的事做了没有），不是**没收文件**。
   没收的代价实测是"半小时的活儿消失 + 回执地址 404 + 她以为写丢了"。
   - 备选（否）：继续没收，但终态时把 `*.html` 认领回来 —— 那是给错误机制打补丁，且"我们动她的东西"。
   - 备选（否）：每轮开工把上一轮产物移进 `prev/` —— 同样是"我们动她的东西"，而 `sinceMs` 零副作用。
2. **`sinceMs` 用时间戳而不是"发一份清单给她"**：零侵入、可测、不依赖她的自述（契约 68 判据取文件事实）。
3. **`NOTES.md` 用"本轮动过"而不是"本轮内容变了"**：逐节哈希更精确，但要在 runner 侧维护四份快照，
   而"动过笔记"已经足以挡住"上一轮的自评被当成本轮的"这类错误；过度精确会把 `append` 习惯判死。
4. **超时仍不自动重投**：`unknown` 的语义不变（契约：无法确认就别重来）。
   修的是"本来就不该在 1800s 内做完的活给了 1800s"，不是"把 unknown 变成成功"。
5. **`.tmp/` 用 `SKIP_DIRS` 而不是放行**：放行它会让快照仍然遍历上千个缓存文件（每阶段两次 I/O），
   还让"删了没记"这类判断被缓存噪音淹没。

## 测试计划

- runner：`phaseAllowlist` 分层（`public/` 仅 publish；`NOTES*.md`/`drafts`/`shots`/`vendor`/根页面全通）；
  `.tmp/` 不进快照；`collectFacts(ws, sinceMs)` 只返回本轮动过的；`timeoutForPhase`
- core：`advanceLoop` 在 `notesMtime < sinceMs` 时 **stay**（上一轮的笔记不算这一轮）
- 真机：开一个只要求「写一句话」的探针任务，确认它**不再**把已有页面移进 `.phases/`
