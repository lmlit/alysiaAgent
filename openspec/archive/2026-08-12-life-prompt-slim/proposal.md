# Change Proposal: life-prompt-slim

## 元信息

- **日期**: 2026-08-12
- **类型**: FEATURE（ai-life 二期①：主提示词瘦身）
- **状态**: pending
- **影响 spec**: ai-life-system（§10 事件流注入）

## 动机（为什么做）

`getLifeEventInjection()` 每次对话**全量注入今天事件**（一天 5-10 条 × 50-100
字）+ 近 7 天摘要——对话 prompt 膨胀，LLM 注意力被 bot 独处细节稀释。

## 需求（做什么）

1. **今天事件截断**：只注入最近 3 条（按时间倒序）——今天的"近期时间线"
2. **预算上限**：注入块总长 ≤ 500 字（今天事件 + 摘要合算），超出优先保留
   最近事件、丢弃最旧摘要
3. 更早/更多细节：靠事件向量检索（二期②）在相关时召回——瘦身 + 检索配对

## 设计决策

- 3 条窗口：bot 的"当下状态"够用（正在做的事 + 最近一两件事）
- 摘要层（近 7 天）本来就是压缩的（一行一条），保留
- 不改变事件存储（全量仍在库，检索兜底）

## 对账方向确认

- [x] 二期立项项① → 本 change 实现

## 测试计划

- 今天 1 条 → 全注入；今天 5 条 → 只注入最近 3 条（倒序）
- 总长超预算 → 截断摘要优先保事件
- 无事件/摘要 → 空注入
- 全量回归
