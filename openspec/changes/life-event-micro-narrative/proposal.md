# Change Proposal: life-event-micro-narrative

## 元信息

- **日期**: 2026-08-28
- **类型**: MODIFY（改现有行为）
- **状态**: proposed
- **影响 spec**: `ai-life-system`

## 动机（为什么做）

用户反馈：生活事件"像人物（人设表演），不像真实事件"——每次产出 1-2 句符合人设的快照独白，无前因后果、无过程变化、无他者环境。真实生活是**有前因、有过程、有后果、有变化的连续片段**。

差距根源：
1. **"1-2 句"约束**锁死快照粒度
2. **延续是可选**——默认开新事件，真实生活 80% 是"继续刚才的事"
3. **无后果/变化意识**——事件发生后世界不变

## 需求（做什么）

- [ ] 事件生成约束放宽：1-2 句 → **2-4 句微叙事**（前因-过程-后果/变化），post-check 长度 ≤80 → ≤150
- [ ] **延续变主路径**：有【你正在做的事】时默认续写推进（进展/波折/被打断/变化），生活自然收尾才开新事件（continuation_of 从可选项变默认倾向）
- [ ] prompt 重构：【你正在做的事】块强化"继续推进它"；9 条约束第 ⑨ 条"第一人称 1-2 句"改为"有前因后果的小片段"
- [ ] 环境/他者维度：允许环境小事件（猫路过/邻居声音/天气变化）参与事件（在场角色约束不变）

## 设计决策（怎么做，含备选与取舍）

| 决策点 | 结论 | 备选（否决理由） |
|--------|------|------------------|
| 叙事粒度 | 2-4 句微叙事（前因-过程-后果），仍是"一个事件"入库 | 完整剧本段落（事件流/注入预算爆炸） |
| 延续策略 | 【正在做的事】存在 → prompt 明确"优先续写推进，也可自然收尾开新"；收尾时 LLM 给 continuation_of 省略 | 强制续写（事件弧可能拖沓） |
| post-check 长度 | ≤150 字（原 80） | 更大（注入预算 500 字会挤占） |
| 后果表达 | 事件允许"我因此…/所以…/之后…"句式 | 无变化（维持快照病） |
