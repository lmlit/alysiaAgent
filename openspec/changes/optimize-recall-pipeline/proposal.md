# Change Proposal: optimize-recall-pipeline

## 元信息

- **日期**: 2026-09-25
- **类型**: MODIFY（召回质量）
- **状态**: in_progress
- **影响 spec**: `memory-system`（召回管道）

## 动机（为什么做）

用真实数据跑召回探针（`packages/server/scripts/recall-probe.ts`），实测三处缺陷：

### 缺陷 1：相似度映射刻度退化

`LanceDBStore.search` 里 `score = max(0, 1 - L2距离)`。向量确认是**单位向量**（模长 1.000），
单位向量下 `L2 = √(2−2cos)`，所以：

| L2 距离 | 对应 cos | `1-d` | 余弦 `1-d²/2` |
|---|---|---|---|
| 0.512 | 0.869 | 0.488 | 0.869 |
| 0.895 | 0.599 | **0.105** | 0.599 |
| 1.004 | 0.496 | **0.000** | 0.496 |
| 1.425 | ~0 | 0.000 | 0.000 |

**旧公式从 d=1（cos=0.5，仍算相关）就归零**，可用区间被砍掉一半。

### 缺陷 2：跨来源合并按绝对分数排序，长的来源被系统性饿死

实测「你最近都在做什么呀」：最近的 8 条**全是 chat**（短问句互相像）；
**46 条 `life_event` 向量一条都进不了最终 5 条**。

根因不是"没嵌入"（实测 46 条在库、单独查能返回很贴切的"浇多肉/绿萝开花"），而是：
- 生活事件是 2-4 句**长微叙事**，与**短查询**的嵌入天然距离远（d≈1.42）
- 全塌成 0 分后排序失效 → 退化为合并顺序 `[会话, 知识, 聊天, 生活]`
- `.slice(0, limit)` → 生活事件排最后，**永远被切**

**核心洞察**：**路内排名可信，跨路比较绝对分不可信**。
每路各自的 topK 是"该来源内最相关的"，但不同来源的文本长度分布不同，
绝对分不可比。用一个全局 sort 合并各路结果，等于让"文本短的来源"系统性获胜。

### 缺陷 3：无相似度过滤

「帮我讲讲量子力学的波函数坍缩」也返回满 5 条（内容全是聊花聊猫）。

## 需求（做什么）

- [ ] `LanceDBStore.search`：相似度改用**余弦** `cos = 1 − d²/2`（单位向量前提已在数据上验证）
- [ ] `MemoryManager.read` 合并策略：**保底配额 + 分数补位**，不再全局 sort 后 slice
- [ ] **路内相对阈值**：某条明显差于该来源最佳（如 < best × 0.7）则丢弃 ——
      **自适应，不受长短文本的绝对分差异影响**
- [ ] 显式不引入**全局绝对阈值**（见「设计决策 3」）
- [ ] 探针脚本复跑对比 + 补单测

## 设计决策（怎么做，含备选与取舍）

**决策 1：合并改"保底配额 + 分数补位"**

每路先取 top-1 保底（会话 / 知识 / 聊天事件 / 生活事件），剩余名额按分数从所有候选补。
某路无候选则该名额让给其他路。

备选是**组间轮转**（第 1 轮各取第 1 名、第 2 轮各取第 2 名…）。否决：路数少时（4 路）
轮转会让第 2 名以后的低质量结果也占位，且 limit=5 时第 2 轮只剩 1 个名额，行为不直观。

**决策 2：阈值做成"路内相对"而非"全局绝对"**

绝对阈值会在长短文本差异下**给生活事件判死刑**（它们的最佳也在 d≈1.4）。
相对阈值问的是"这条比该来源最佳差多少"，与文本长度分布无关，才是可比的。

**决策 3：明确不做全局绝对阈值**

同理——绝对分跨来源不可比，加全局阈值只会系统性砍掉长文本来源。

**决策 4：`importance_threshold` 旋钮继续空转，本 change 不修**

`applyKnobsToRetrieved` 里有 `metadata.importance > 阈值 → +0.15`，但**四条写入路径
没有一条写 `importance`**，该分支从未执行。

不在本 change 修：定义"什么算重要"是**产品语义决策**（生命周期？情绪强度？用户显式标记？），
不是召回管道的优化。需要单独讨论 —— 候选信号：生活事件有 `moodDelta`、消息有 `source`。

**决策 5：`confirmation_bias` / `retention_bias` 同样不接**

它们要的是"记忆的情绪极性"与"与既有信念的冲突度"，当前数据里都没有这两个信号。
硬接会变成一个没有输入的旋钮（和 `importance` 一样的空转）。先如实留着。
