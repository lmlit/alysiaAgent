## 一句话

从「把一份外部写的实施计划落地」，做到「她能在自己的服务器上接活、自己看、自己发布、
自己决定做什么，并且**做东西必须来回改**」——每一步都有判据、有边界、有回执。

**如果只记三件事**：

1. **权限是对的**：删库/读凭据不是"需要审批"，是**根本做不到**（实测 8/8 读不到）
2. **味道是从来回里长出来的**：加了 6 阶段状态机后，她第一轮就写出
   「b 又把夜色请回来了，**这是我这一轮最该认的错**」
3. **我搞挂过站点约 10 分钟**（模块 `provides` 未声明 ⇒ 整个进程起不来），教训写进契约 64

## 一、做了什么

### A. 委托链路：她能接活

- `project_tasks` 表 + 状态机（`queued`/`running`/`needs_review`/`completed`/`failed`/`unknown`）
- `requestKey` 去重、单项目单并发、认领超时回收
- 常驻 runner（systemd）**一个服务管所有项目**：服务端挑"还有活的最老项目"
- 执行：`dsh --profile alysia --json`，结果 `POST /api/project-tasks/:id/result` 回传
- 三个聊天工具：`start_project_task` / `get_project_task` / `continue_project_task`

### B. 权限：能力边界优先，不是审批优先

- 降权用户 `alysia-runner`（非 root）、独立 `DSH_HOME`、工作区 `<workspace>/{blog,toys}`
- 实测 **8/8 读不到**：`/root`、`alysia.db`、`.env`、`.credentials.yaml` 等
- 方向排序：**能力边界 > 审批 > 指令黑名单**
  （黑名单永远会漏；判据若来自模型自述，等于没有闸）

### C. 记忆与归属

- 委托会话**不进**画像/摘要/嵌入 —— 否则"帮我做个博客"会被提取成**用户事实**
- 结果**回到原会话**（她记得自己做过什么）
- ★ 回执改 `role: 'engine'`（工程端）：之前用 `assistant` 会在 prompt 里显示成
  「昔涟：（委托任务回执）…」，**等于伪造她说话**。她的口吻只用于 QQ 推送。

### D. 展示层：基站

- `<hub dir>` + `p/<项目>` 符号链接，10 秒 timer 重建（幂等、原子替换、自动删除下线项）
- 端口 **3389**（安全组只放 22 与 3389）
- **按页面**列卡片（她加页面就自动出现），会话结束时共 **11 页**

### E. 她"看得见"

- `shot.sh` = 一台相机（headless Chromium + Noto CJK），把页面变成她能打开的图
- 实测：给一张无任何文字说明的随机码图片，她准确读出 6 位码与两个圆点的位置/颜色
  ⇒ **文档里不许再写"她看不见图"**
- `--vision`（GLM-4V）只是**旁路**，她自己看更准

### F. 成本闸门

- 执行窗口：北京时间**工作日 9:00–12:00 / 14:00–18:00 只排队不执行**；
  其余（周末、节假日）可跑
- `GET /api/project-tasks/window` 直接回答"我的任务为什么不动"
- 排障用 `projectTasks.nowOverride`（配了会 WARN，验完删）

### G. 自主性：她自己发起

- 六道护栏按顺序：开关 → 空闲时段 → 无在途 → 日上限（默认 1）→ 间隔（24h）→ **用户已安静（6h）**
- **默认不发布**：她决定做什么，"上线"留给对话里的人
- **必须显式 `projectId`**：猜项目 = 猜她往哪个工作区写文件，**不许猜**
- 真机一次：她自己想出「24 小时才转一圈的慢时钟」（指针走过的颜色从靛蓝化开到黎明的橘）

### H. ★ 迭代状态机（本次重点）

```
intent → sketch → review → build → revise → statement → publish → done
```

- **判据取文件事实**：`NOTES.md` 的四个标记（`## 意图`/`## 自评`/`## 选的`/`## 哪里像我`）、
  `drafts/*.html` 数量、`shots/draft-*.png`、`shots/revise-N.png`、根目录页面、`public/` 同名页
- **不许采信"我改好了"**这类自述（本项目已栽过同类：回执自述 ≠ 真做完）
- 硬下限：≥2 张草图且每张都拍过、必须有 1 轮改动、必须写出「哪里像我」
- `maxRounds = 8`（对应 LangGraph 的 `recursion_limit`），超了交给人
- 每阶段一次**独立**执行端运行（不是让模型在一轮里自己走完六步 —— 那正是原来的毛病）
- 阶段指令只在服务端定义一次，随认领响应下发（`nextPrompt`）

**真机轨迹**（6 阶段 6 次运行，全部由文件事实判定通过）：

```
intent    → sketch    · 意图已写（242 字）
sketch    → review    · 3 个草图都有截图
review    → build     · 已选 a，自评 1331 字
build     → revise    · 完整版已就位：waiting.html
revise    → statement · 已拍过一轮并改过（revisions=1）
statement → done（ready）
```

### I. 通知改造

- 通知注入**最近对话**（与聊天回复同源）⇒ 不再是"通用人格"
- 她自己写的「哪里像我」**原文**（截断 260 字）随通知送达（`她自己的话：…`），不经模型改写
- 通知草稿**记进日志**：部署后可无副作用验证，不必为了验收真给用户发一条 QQ

### J. 阶段外写入：硬拦 + 不销毁

- 阶段开始前快照（路径 → `size:mtime`），结束后比对**白名单**
- 越界的**新增/修改**移出到 `<workspace>/.phases/violations/r<N>/`（**不删**），删除也记一笔
- 越界条目写进回执：`[阶段外写入已移出] 新增 lift.html`
- 理由：回滚是"我们改了她的东西"，必须让她看见，否则她会以为自己写丢了

## 二、踩过的坑（本档最值钱的部分）

| # | 坑 | 代价 | 现在的防线 |
|---|---|---|---|
| 1 | 模块 `provides: false` 却调 `ctx.provide()` | **整站挂约 10 分钟**，容器重启 7 次 | 契约 64：那不是"模块挂了"，是全站挂了 |
| 2 | 构建失败仍 `save` ⇒ 部署旧镜像 | **踩了 3 次**，"改动没生效"的假象 | 构建重试 + 失败即停；**load 后 grep 新标记**，不通过就停 |
| 3 | 服务器 python **3.6** 的 `http.server` 是单线程 | 并发时间歇 `000`（`Recv-Q 6`） | `ThreadingMixIn`；另两个坑：`directory=` 是 3.7 才有；`realpath` 会把 `p/<项目>` 符号链接判成越狱、页面静默回落成基站首页 |
| 4 | 日志块缓冲 | 用户报 404，日志里**一条都没有** | 写日志后显式 `flush()` |
| 5 | `loadConfig()` 逐字段挑选 | 新配置段**静默丢弃**（踩 2 次） | 新增配置必须显式映射 |
| 6 | `max_tokens` 给小 | 返回**空串**（KI-1 形状：`finish=length`） | 自发起 200 → 800 |
| 7 | 回执写 `role: 'assistant'` | **冒充她说话** | `engine` 归属 + 共享渲染器；她的话只进推送 |
| 8 | 正则 `(?=^##\s\|$)` 配 `m` | `$` 在标题行尾立刻命中 ⇒ 捕获恒空，**一次挂 7 条用例** | 改逐行扫描 |
| 9 | 自发起"留空就用最后一个项目" | 她落到**正式页面**项目 | 必须显式 `projectId`，留空不发 |
| 10 | PowerShell 引号 / BOM / 提交信息 | 反复失败 | 用 `write` 写文件、`git commit -F` |
| 11 | Clash 的 HTTP CONNECT 不通 | `git push` 超时 | **必须 `socks5h://127.0.0.1:7897`**；关客户端后要**同时关系统代理**（否则指向死端口，浏览器全断） |
| 12 | shell 用 `${VAR:-默认}` | **泄露过一次 API key** | 只用 `[ -n "$VAR" ]`，禁止 `:-` / `:+` |

### 四补、当晚真机复核发现的三个结构性问题（2026-10-18 23:0x–23:4x）

> 起因：用户 QQ 实测「让她做个网站」→ 回执给的链接打开是她凌晨做的「月光花园」。
> 修链接时在服务器上把整条链路跑通看了一遍，撞出下面三条。**链接已修**（change
> `fix-receipt-link-to-produced-page`），这三条**只登记不改**。

| # | 问题 | 判据（可复现） | 为什么难自己发现 |
|---|---|---|---|
| 1 | **阶段白名单会把她的真页面没收** | `sketch` 阶段允许的只有 `drafts/*.html` + `shots/draft-*`；她在 sketch 轮把整页写进根目录 ⇒ 轮末 `rollbackOutOfPhase` 把它移进 `.phases/violations/<r>/`。两次实测：**988 个文件**（含她自己 17 张 shots + `vendor/three.min.js`）、**53 个文件**（含 `island.html` 整页） | 日志只说「阶段外写入 N 处（已移出）」，看起来"没删就行"；但页面从工作区消失了 ⇒ 回执里的地址会 404 |
| 2 | **闸门判据不区分任务** | `sketch` 只要求「`drafts/` 有 ≥2 个 html 且各有 `shots/draft-*.png`」，读的是**整个工作区**。同一工作区做第二个任务时，上一轮的 `a/b/c.html` 与截图还在 ⇒ **这一轮什么都不做也能过**（10-18 14:28 日志「6 个草图都有截图」就是旧文件）；`review` 的「## 自评」「## 选的」同理 | 判决写的是"通过"，看不出它读的是旧文件 |
| 3 | **build 类重阶段 1800s 必超时** | `runDsh` 的 `timeoutSec` 默认 1800；海岛那轮 build 卡在 npm 下 three.js + 反复截图，**1801s 被 SIGKILL** ⇒ `mapOutcome` 判 `unknown`（**有意不自动重投**）⇒ 任务永久卡死，只能让用户重开，而重开又从 `intent` 走一遍六阶段（成本 6 倍） | 用户侧只看到"她一直在跑" |

**共同根因**：状态机假设「每个任务都在干净工作区从头做」，实际是**同一个工作区反复做同一类东西** ——
判据看全工作区文件、白名单按路径不按权限，两边都不带"这一轮"的坐标。

| # | 修法 |
