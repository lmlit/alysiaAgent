# 更新日志

本文件记录「绿野 Luye」主题的全部版本变更。

版本号规则：修复问题发 patch（`X.Y.Z`），新增功能发 minor（`X.Y.0`），不兼容改动发 major（`X.0.0`）。

每个版本均经过 Halo 2.26.1 真机环境验证（安装、升级、全路径扫描、移动端视口与横向溢出检查）。

## 1.3.3

优化首页阅读排版与首屏信息密度：普通文章摘要提升为 16px / 400 并改用正文色，精选卡摘要提升为 15px，弱化文字颜色提高对比度；桌面内容容器由 1200px 加宽至 1280px，文章正文排版保持不变；置顶卡封面桌面比例调整为 3.4:1 并限制最大高度 340px，移动端使用独立的 2:1 比例。已在 Halo 2.26.1 真机环境完成 grid / list 两种布局及 1440 / 390 / 320px 三档视口验证，无横向溢出或置顶文章重复渲染回归。相关 PR：#13。

## 1.3.2

修复首页精选专题、无封面置顶文章与无 JavaScript 时的内容显示。精选专题改为从全部已发布文章中筛选带封面的文章，避免最新 10 篇均无封面时错误留空；没有符合条件的文章时隐藏整个区块，并将变量声明移至外层 `th:block`，确保 Thymeleaf 按正确顺序求值。置顶大卡不再以封面为必要条件，grid / list 两种布局下无封面置顶文章均只渲染一次且不输出空封面图。滚动显现改为仅在 `main.js` 初始化后添加 `reveal-ready`，脚本未加载或未执行时内容保持可见。已在 Halo 2.26.1 + H2 真机环境验证上述场景，并通过 CDP 禁用脚本确认首页、分类页和标签页的 `.reveal` 元素均为可见状态。

## 1.3.1

文章卡片新增浏览量徽章——首页（精选专题 / 置顶大卡 / 网格卡）、归档、分类、标签、作者页的文章卡片统一显示「眼睛图标 + 浏览次数」胶囊，悬停提示「N 次阅读」。统计直接取自 Halo 内置的 `Counter` 扩展，主题侧不自行计数，也不额外发起请求；`post.stats` 为空（文章尚无统计记录）时自动不渲染徽章，不会显示占位零值。主题设置「文章列表」组新增「显示文章浏览量」开关（默认开启，未配置时同样按开启处理，老站点升级即生效），关闭后全部卡片不再显示。已在 Halo 2.26.1 真机环境验证：四类卡片全部正确渲染真实数值，开关开/关双向生效，1440 / 390 / 320px 三档视口下均无横向溢出。

## 1.3.0

新增前台「控制台」入口——导航栏右上角增加控制台图标按钮、页脚联系方式行增加「控制台」胶囊，点击直达站点后台；主题设置「基础」组新增「显示控制台入口」开关（默认开启）与「控制台路径」配置（默认 `/console`），关闭开关后两处入口同时隐藏，便于不向前台访客暴露后台地址。同时修复窄屏导航溢出：≤640px 隐藏导航栏控制台按钮（页脚入口保留），≤480px 收紧导航间距并让过长的站点名以省略号截断，320px 起不再出现横向滚动条。

## 1.2.0

补充所有主题页面的独立标题、分页和按年月归档的规范链接、社交分享标签及文章 BlogPosting JSON-LD；提供两个独立 SEO 开关以兼容插件。新增可配置的个人主页入口，文章封面使用文章标题作为替代文字，并修正外站链接的导航高亮。

## 1.1.2

修复代码高亮插件的配色被主题覆盖。根因为 CSS 层：`.post-content code` 与 `.post-content pre code` 无条件设置了绿色背景与文字色，插件注入的 `hljs` 类代码块也被这条规则命中，导致高亮配色被压成主题绿；`pre` 上的深绿底 `background:#0A1712` 同样会盖住插件的代码块背景。修复后绿色配色改为 `.post-content code:not(.hljs)` 兜底——插件已接管的高亮代码块背景与文字色完全交给插件，未安装插件时的普通代码块仍保持绿野深绿风格；`pre:has(>code.hljs)` 让已高亮的代码块容器让出背景。另在 `layout.html` 的 `<html>` 上补 `data-color-scheme="dark"`，供 Shiki 等按页面配色方案选择暗色高亮主题的插件识别。README 同步新增「代码块高亮」章节，说明 highlight.js 与 Shiki 的配置方式。

## 1.1.1

修复首页「精选专题」区文章封面不显示。根因为模板层：卡片用 `spec.cover` 筛选文章却从未输出该字段，只渲染装饰叶子图；同时 `.featured-cover img` 为无类名通配选择器，会将区内所有图片压缩为右上角 40px 水印。修复后封面以 `object-fit:cover` 铺满卡片，原有渐变底保留作为兜底——文章无封面或封面地址失效时均不会塌陷。已在 Halo 2.26.0 真机环境验证：有封面正常渲染、清空封面后该文自动跳过、封面 404 时渐变底透出且高度不变；首页、归档、文章、分类、标签等全路径及移动端单列布局均正常。

## 1.1.0

首页信息层次升级——新增 Hero 数据徽章行（文章/分类/标签自动统计，琥珀色 `#E8B96E` 暖色点缀）、「精选专题」区（自动取最近 3 篇带封面的文章）、双列网格文章布局（可在设置中切回经典纵向列表）、首页作者卡片，导航栏支持搜索入口（需填写搜索页链接）。全部新模块均可通过主题设置开关或改写文案。

## 1.0.1

修复首页 HTTP 500（布局契约中 `head` 片段因 `th:replace` 优先级高于 `th:if`，在传 null 时解析失败）；日期格式化改用核心 `#dates` 表达式（Halo 未注册 `#temporals` 方言）；修复作者归档页字段路径（`UserVo` 的 displayName/avatar/bio 位于 `spec` 下）。已在 Halo 2.26.0 真机环境完成手动安装、启用，以及首页、分页、归档、分类、标签、文章、独立页、「关于我」自定义模板、作者页、404 的全路径验证。
